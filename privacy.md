# Islnd privacy policy

Last updated: 18 November 2026

Islnd does not collect, send or sell any data. It has no server, no account, no analytics and no ads.

## What it reads, only inside the browser

- **History**: the pages that match what you type, shown as suggestions. They can be turned off in the settings › General › Behaviour.
- **Tabs**: the address, title and favicon of the current tab, and the tabs the commands act on. Reopen closed tab uses the list of recently closed tabs.
- **Bookmarks**: whether the current page is bookmarked, for the Bookmark page / Remove bookmark command.
- **Pages**: Islnd appears on the pages you visit. A screenshot is taken only when you run a Screenshot command: it opens in a new tab and leaves the browser only if you copy or save it.

## What it stores

- **Settings**: in the browser's synced storage. If you sync your browser with an account, the browser syncs them like its own settings.
- **Favicons of your links**: in the browser's local storage, on this device only.
- **Screenshots**: the latest ten, in the browser's local storage, on this device only, so their tab can show them again after a reload. Each one stays until ten newer screenshots replace it, or until Islnd is removed.
- **Exported settings**: only in the file you save, where you choose.

## Network requests

- Searches go to the browser's default search engine, through the browser.
- When you add a link in the settings, Islnd reads that page's title and favicon from the site, without cookies.
- Where the browser offers extensions no favicon service, Islnd loads the current tab's favicon from the address the browser shows for it, usually from its own cache.
- Islnd makes no other requests.
